Avec react-native : 0.81.5 

react-native-screens: 		3.31.1	>= 3.36.x 	= 4.4.0
react-native-svg: 		15.2.0	>= 15.4.x 	= 15.10.1
react-native-safe-area-context: 4.10.5	>= 4.10.6 	= 5.0.0 

# 1. Supprimez les anciens dossiers de dépendances et fichiers de verrouillage
Remove-Item -Recurse -Force .\node_modules\
Remove-Item -Force .\package-lock.json

# 2. Réinstallez proprement les packages avec les nouvelles versions du package.json
npm install

# 3. Vérification de conformité globale pour s'assurer qu'aucune autre dépendance cachée ne va faire échouer le build Android
npx expo install --check

# 4. Relancer le Build de l'APK en renvoyant le projet sur les serveurs EAS

eas build --platform android --profile preview

### Pourquoi cette méthode fonctionne ?
En passant `react-native-screens` en version `~4.4.0` et `react-native-svg` en `~15.10.1`, le code source C++ de ces modules intègre désormais les modifications d'architecture de React Native 0.81.5. Le compilateur (`ninja` / `clang++`) présent sur les serveurs d'Expo trouvera toutes les références de fonctions nécessaires et terminera la génération de votre APK avec succès.
